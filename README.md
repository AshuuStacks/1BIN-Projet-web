Vinci Court – Application web de gestion d’un club de tennis

Développement d’une application web en JavaScript avec Node.js, Express, Handlebars et SQLite, selon l’architecture MVC.

Fonctionnalités principales :
- Gestion des réservations et des disponibilités des terrains.
- Création de tournois et gestion des inscriptions des participants.
- Gestion des utilisateurs et des entraîneurs.
- Authentification et gestion des accès.
- Intégration d’une base de données relationnelle SQLite pour la persistance des données.
- Génération de pages dynamiques avec Handlebars.

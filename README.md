# Projet web 2024 - Groupe XX

Ce repository GitHub reprend le boilerplate du code de votre projet web, ou la base à partir de laquelle vous allez déveloper.

## Apprentissage de Git et GitHub

Suivez le document proposé sur moodle pour apprendre à utiliser Git et GitHub durant votre projet.

## Installation du projet

Quand vous clonez ce repository sur votre machine, vous devez installer les dépendances et la base de données. Exécutez la commande suivante dans un terminal ouvert à la racine du projet :

```bash
bash install.sh
```

## Lancer le projet

Une fois que le projet est préparé tel qu'expliqué dans la section précédente, vous pouvez le lancer avec les commandes suivantes dans un terminal ouvert à la racine du projet :

```sh
npm start
```

## Préparation de la soumission

Lorsque vous voudrez soumettre votre projet, utilisez la commande suivante pour créer votre archive :

```bash
bash prepare_submission.sh
```

Si votre projet est fonctionnel, cette commande va créer un fichier `project_group_XX_FRISTNAME_LASTNAME.zip`. Autrement, la commande affiche une erreur dans le terminal.
